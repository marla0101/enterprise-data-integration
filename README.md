# Enterprise Data Integration

Integration service resources used across finance, supplier operations, workforce reporting, and service monitoring.

## Repository structure

- `deployment/`: runtime configuration snapshots
- `application/`: service connector settings
- `cloud/`: infrastructure inventory and access assignments
- `data/`: scheduled financial and workforce extracts
- `partners/`: partner access registry
- `soc/`: service monitoring reference
- `control/`: delivery and release notes
